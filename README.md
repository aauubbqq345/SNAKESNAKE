   # 🐍 Snake Turbo

   Процедурная многопользовательская змейка с бесконечной картой, написанная на Python и Pygame.

   ## 🎮 Особенности
   - 4 режима игры: Классик, Призрак, Сапёр и Хакер (с IT-викториной!)
   - Сетевая игра до 4 игроков по локальной сети
   - Динамическая генерация карты, бонусы, комбо и боссы-боты
   - Кастомные спрайты и анимации

   ## 🕹️ Управление
   - `WASD` или `Стрелки` — движение
   - `Shift` — рывок
   - `Пробел` — пауза
   - `M` — звук вкл/выкл
   - `Tab` (в сети) — таблица лидеров хакеров

   ## 🚀 Как запустить (для игроков)
   1. Скачай архив `SnakeTurbo-Windows.zip` или `SnakeTurbo-Linux.tar.gz` из раздела [Releases](https://github.com/ТВОЙ_НИК/SnakeTurbo/releases).
   2. Распакуй архив.
   3. Запусти `SnakeTurbo.exe` (Windows) или `./SnakeTurbo` (Linux).
   4. Python устанавливать не нужно!
